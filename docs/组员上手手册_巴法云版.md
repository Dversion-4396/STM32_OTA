## 第零章：三分钟了解这个项目

### 0.1 要做什么

做一套 **STM32 远程固件升级（OTA）系统**：

```
手机/电脑 发命令  →  云端  →  4G 模块  →  STM32 下载新固件
                                              ↓
                                        存到外部 Flash
                                              ↓
                                        重启 → BootLoader 搬移
                                              ↓
                                        运行新程序
```

### 0.2 分成四块

| 人 | 负责 | 核心文件 |
|---|---|---|
| **A** | 4G 通信 + HTTP 下载 | `APP工程/user/api/cat1.c` |
| **B** | BootLoader + Flash 分区 | `BootLoader工程/user/api/boot.c` `stmflash.c` |
| **C** | 巴法云 MQTT + 升级包 | `APP工程/user/api/mqtt.c` |
| **D** | SPI Flash 驱动 + 集成 | `APP工程/user/api/spi.c` `main.c` |

## 第二章：必读的五个坑（不看你一定踩）

### 坑 1：IROM1 启动地址会变

**这是最容易让人抓狂的坑 —— 程序烧录成功但串口一点输出都没有。**

| 阶段 | IROM1 | VECT_TAB_OFFSET | 什么时候用 |
|---|---|---|---|
| **现在（单独调 APP）** | `0x08000000` / `0x80000` | `0x0` | 板子上没烧 BootLoader |
| **集成 OTA 时** | `0x08008000` / `0x78000` | `0x8000` | 给 BootLoader 让 32KB |

**怎么改 IROM1：**

```
Keil → Options for Target（魔术棒图标）→ Target 标签
→ 右侧 IROM1 的 Start / Size
```

**怎么改 VECT_TAB_OFFSET：**

改 `APP工程/libraries/CMSIS/system_stm32f10x.c`：

```c
/* 阶段①（单独调 APP）*/
#define VECT_TAB_OFFSET  0x0

/* 阶段②（集成 OTA）*/
#define VECT_TAB_OFFSET  0x8000
```

**★ 这两个必须成对修改，只改一个会出问题 ★**

**症状对照：**

| 现象 | 原因 |
|---|---|
| 烧录成功但串口无输出 | IROM1 和 VECT_TAB_OFFSET 不匹配，程序跑飞了 |
| 程序能跑但中断不进 | 只改了一个 |

### 坑 2：串口波特率必须一致

```
单片机 USART1：9600（定义在 common.h 的 USART1_BRR）
串口助手：    必须也设 9600
```

**不一致的现象：乱码，或者什么都不显示。**

**4G 模块的 USART3 是 115200**，两个串口波特率不同，别搞混。

### 坑 3：4G 模块只在开机时读 SIM 卡

```
错误顺序：先上电 → 后插卡  → 一直报 +CME ERROR: 10
正确顺序：断电 → 插卡 → 上电 → 等 15 秒
```

**卡插好了但模块不认，八成是这个原因。**

### 坑 4：AT 指令必须以 `\r\n` 结尾

```c
Usart3_SendString("AT");
Usart3_SendString("\r\n");    // ★这条不加，模块只回显不执行★
```

**用串口助手手动测时，要勾"发送新行"。**

### 坑 5：中断里绝对不能调 SendString

```c
// ❌ 死锁
void USART1_IRQHandler(void)
{
    Usart1_SendString("收到数据\r\n");   // SendByte 里死等 TC 标志
}

// ✅ 正确
void USART1_IRQHandler(void)
{
    usart1_value.flag = 1;              // 只置标志，主循环处理
}
```

**原因**：`Usart1_SendByte` 里有 `while(!(USART1->SR & TC))`，中断里发送时如果主程序也在发送，两边等同一个标志 → 永久死锁。

#### 第二步：`CAT1_HttpInit`

**函数签名：**

```c
u8 CAT1_HttpInit(char *url)
{
    /* TODO【A】：实现 */
    return 1;
}
```

**返回码设计：**

```
0 = 成功
1 = HTTPINIT 失败
2 = 设置 CID 失败
3 = 设置 URL 失败
4 = HTTPACTION 发送失败
5 = 服务器返回非 200
6 = 等响应超时
```

**实现步骤：**

```c
u8 CAT1_HttpInit(char *url)
{
    char cmd[600];      /* ★600 字节，URL 可能很长★ */
    u16 i;

    /* 1. 启动 HTTP 服务 */
    /* 先 TERM 清残留（返回 ERROR 是正常的，忽略）*/
    CAT1_SendAT("AT+HTTPTERM", "OK", 2000);
    if (CAT1_SendAT("AT+HTTPINIT", "OK", 5000)) return 1;

    /* 2. 绑定 PDP 上下文 */
    if (CAT1_SendAT("AT+HTTPPARA=\"CID\",1", "OK", 3000)) return 2;

    /* 3. 设置下载 URL */
    sprintf(cmd, "AT+HTTPPARA=\"URL\",\"%s\"", url);
    if (CAT1_SendAT(cmd, "OK", 5000)) return 3;

    /* 4. 发起 GET 请求 */
    if (CAT1_SendAT("AT+HTTPACTION=0", "OK", 5000)) return 4;

    /* 5. ★等异步结果（关键！）★ */
    for (i = 0; i < 300; i++)      /* 最多等 30 秒 */
    {
        delay_ms(100);

        if (usart3_value.flag)
        {
            if (usart3_value.count < USART3_BUFFER_SIZE)
                usart3_value.data[usart3_value.count] = 0;

            if (strstr((char *)usart3_value.data, "+HTTPACTION: 0,200"))
                return 0;           /* 200 = 成功 */

            if (strstr((char *)usart3_value.data, "+HTTPACTION: 0,"))
                return 5;           /* 其他状态码 = 失败 */

            usart3_value.flag = 0;
        }
    }
    return 6;
}
```

**★ 两个坑 ★**

**坑 1：`AT+HTTPACTION=0` 的响应是两段**

```
发送 AT+HTTPACTION=0
立即回：OK                          ← 指令收到了
等几秒：+HTTPACTION: 0,200,12345    ← 下载完成
```

**第 4 步 `SendAT` 找到 OK 就返回了，但下载还没完，必须第 5 步单独等第二段。**

**坑 2：`AT+HTTPTERM` 返回 ERROR 是正常的**

HTTP 服务没初始化过时，TERM 一定报错，不能拿它判断成败。

#### 第三步：`CAT1_HttpRead`

**函数签名：**

```c
u8 CAT1_HttpRead(u32 offset, u16 len, u8 *outbuf)
{
    /* TODO【A】：实现 */
    return 1;
}
```

**返回码：**

```
0 = 成功
1 = 超时（SendAT 失败）
2 = 数据不完整或定位失败
```

**实现：**

```c
u8 CAT1_HttpRead(u32 offset, u16 len, u8 *outbuf)
{
    char cmd[64];
    char expect[32];
    u8  *ptr;
    u16  avail;

    /* 1. 拼指令和期望响应 */
    sprintf(cmd,    "AT+HTTPREAD=%lu,%u", (unsigned long)offset, len);
    sprintf(expect, "+HTTPREAD: %u", len);

    /* 2. 发指令，等 +HTTPREAD: 256 头部 */
    if (CAT1_SendAT(cmd, expect, 8000)) return 1;

    /* 3. 定位数据起始位置 */
    ptr = (u8 *)strstr((char *)usart3_value.data, expect);
    if (ptr == NULL) return 2;

    ptr += strlen(expect);                    /* 跳过 "+HTTPREAD: 256" */

    while (*ptr == '\r' || *ptr == '\n') ptr++;   /* 跳过 \r\n */

    /* 4. ★检查剩余数据够不够 len 字节★ */
    avail = (u16)(usart3_value.count - (u16)(ptr - usart3_value.data));
    if (avail < len) return 2;

    /* 5. ★定长拷贝（不能用 strcpy）★ */
    memcpy(outbuf, ptr, len);

    return 0;
}
```

**★ 两个致命坑 ★**

**坑 1：必须用 `memcpy` 定长拷贝**

固件是二进制，里面全是 `0x00`、`0xFF`。

```c
strcpy(outbuf, ptr);         // ❌ 遇到 0x00 就截断
memcpy(outbuf, ptr, len);    // ✅ 定长拷贝
```

**坑 2：返回数据有头部，要跳过**

```
\r\n+HTTPREAD: 256\r\n<256 字节二进制>\r\nOK\r\n
        ↑            ↑
      跳过这里      从这里开始拷
```

**坑 3：第 4 步的检查是保命的**

如果模块只返回了 200 字节，你 `memcpy` 256 字节会**读到缓冲外**，可能崩溃。

#### 第四步：`CAT1_OTA`

**函数签名：**

```c
u8 CAT1_OTA(char *url, u32 fw_len)
{
    /* TODO【A】：实现 */
    return 1;
}
```

**实现：**

```c
u8 CAT1_OTA(char *url, u32 fw_len)
{
    u32 offset;
    u16 len;
    u16 page = 0;
    u8  buf[256];
    u8  ret;

    /* 1. 激活网络 */
    if (CAT1_ActiveGPRS()) return 2;

    /* 2. HTTP 初始化 + 发起 GET */
    if (CAT1_HttpInit(url)) return 3;

    /* 3. 擦 W25Q128（根据固件大小算擦几块，每块 64KB）*/
    {
        u8 blocks = (u8)((fw_len + 65535) / 65536);
        u8 b;
        if (blocks == 0) blocks = 1;
        for (b = 0; b < blocks; b++) W25Q128_EraseBlock(b);
    }

    /* 4. 分块下载（每块 256 字节 = W25Q128 一页）*/
    for (offset = 0; offset < fw_len; offset += 256)
    {
        len = (u16)((fw_len - offset >= 256) ? 256 : (fw_len - offset));

        ret = CAT1_HttpRead(offset, len, buf);
        if (ret)
        {
            /* 网络抖动，重试一次 */
            delay_ms(200);
            ret = CAT1_HttpRead(offset, len, buf);
            if (ret) return 4;
        }

        W25Q128_WritePage(page++, buf);

        /* 每 4KB 打印进度 */
        if ((page % 16) == 0)
        {
            Usart1_SendString(".");
        }
    }

    /* 5. 关闭 HTTP 服务 */
    CAT1_SendAT("AT+HTTPTERM", "OK", 3000);

    return 0;
}
```

### 4.5 第四步：写 CAT1_ParseOTA（解析 OTA 命令）

**函数在 `cat1.c`，注释里写了完整实现示例。**

**巴法云报文格式（自己定的）：**

```
http://xxx.com/fw.bin,31236,abc123def456
       ↑ URL          ↑ 大小  ↑ MD5（可选）
```

**实现：**

```c
u8 CAT1_ParseOTA(char *msg)
{
    char *p;
    char *url;
    char *size_str;

    /* 1. 找第一个逗号，前面是 URL */
    p = strchr(msg, ',');
    if (p == NULL) return 1;
    *p = '\0';
    url = msg;
    size_str = p + 1;

    /* 2. 找第二个逗号（MD5 可选）*/
    p = strchr(size_str, ',');
    if (p != NULL) *p = '\0';

    /* 3. 保存 */
    if (strlen(url) > OTA_URL_LEN) return 2;
    strcpy((char *)URL_ABuff, url);
    BemfaInfoCB.OTA_firelen = (u32)atoi(size_str);

    /* 4. 校验合理性 */
    if (BemfaInfoCB.OTA_firelen == 0 ||
        BemfaInfoCB.OTA_firelen > FLASH_A_SIZE) return 2;

    Usart1_SendString("[OTA] URL: ");
    Usart1_SendString((char *)URL_ABuff);
    Usart1_SendString("\r\n");

    return 0;
}
```

### 4.6 第五步：打包升级包（28 字节尾缀）

**用仓库里的 `tools/ota_pack.py`：**

```powershell
python tools/ota_pack.py firmware.bin firmware_packed.bin
```

**输出：**

```
原始文件: firmware.bin (31236 字节)
MD5: abc123def456789012345678901234
打包后: firmware_packed.bin (31264 字节 = 31236 + 28)
```

**升级包结构：**

```
┌──────────────────────────┐
│     固件本体（N 字节）     │
├──────────────────────────┤
│ CD EF CD EF              │  4 字节：魔数
│ 原始长度（小端 4 字节）    │  4 字节
│ MD5 裸摘要（16 字节）      │  16 字节
│ FF FF FF FF              │  4 字节：结束标记
└──────────────────────────┘
              共 28 字节
```

### 4.7 固件放哪里（★新增问题★）

**巴法云不托管 `.bin` 文件，要自己找地方放。**

**★★★ 关键坑 ★★★**

```
STM32 走 4G → 运营商内网 IP
你电脑 → 局域网 IP 192.168.x.x
         ↓
这两个网络不通！STM32 下载不到你电脑的文件
```

**所以不能用电脑开 HTTP 服务测试！**

**推荐方案：Gitee 公开仓库**

1. 建一个公开仓库
2. 上传 `fw.bin`
3. 点文件 → 「原始数据」→ 复制链接
4. 链接形如：`https://gitee.com/用户名/仓库名/raw/master/fw.bin`
5. **用手机 4G 流量测试能不能下载**（能下载说明公网可访问）

## 第五章：B 的任务（BootLoader）

### 5.1 完全不受平台变更影响

**BootLoader 的逻辑一点不用改：**

```
上电
 ↓
读 AT24C02 的 OTA_flag
 ↓
是 0x5AA5C33C？
 ├─ 是 → 从 W25Q128 搬固件到片内 Flash 0x08008000
 │        → 清标志
 │        → 跳转到 APP
 └─ 否 → 直接跳转到 APP
```

### 5.2 唯一要注意：common.h 已改

**结构体从 111 字节变成 99 字节。**

**B 如果已经在写，必须重新拉代码，确认 `common.h` 是最新的。**

**`boot.c` 里原来写 `AliInfoCB` 的地方，现在要改成 `BemfaInfoCB`。**

### 5.3 28 字节尾缀格式不变

```
CD EF CD EF + 原始长度(4字节小端) + MD5(16字节) + FF FF FF FF
```

**校验代码不用改。**

### 5.4 B 的任务清单

| 序号 | 函数 | 文件 | 难度 |
|---|---|---|---|
| B1 | `STMFLASH_Write` | `stmflash.c` | ⭐⭐ |
| B2 | `STMFLASH_Read` | `stmflash.c` | ⭐ |
| B3 | `BOOT_CheckOTA` | `boot.c` | ⭐⭐ |
| B4 | `BOOT_CopyFirmware` | `boot.c` | ⭐⭐⭐ |
| B5 | `BOOT_JumpToApp` | `boot.c` | ⭐⭐ |

**★ B4 是核心：从 W25Q128 读 → 写片内 Flash**

**F103 的 Flash 是半字编程（2 字节），不是 G0 的双字（8 字节）。**


### 6.1 SPI + W25Q128（不变）

```c
W25Q128_Init()              检查 JEDEC ID = 0xEF4018
W25Q128_EraseBlock(n)       擦 64KB 块
W25Q128_WritePage(p, buf)   写 256 字节页
```

**接线：**

```
W25Q128    战神V1
```

**★ 注意：PB12 不能当普通 IO ★**

### 6.2 main.c 集成（要改）

**`ActiveEvent` 函数里：**

```c
void ActiveEvent(void)
{
    /* TODO【C】：连接巴法云 */
    if (SysEventFlag & CONNECT_START)
    {
        SysEventFlag &= ~CONNECT_START;
        MQTT_ConnectBemfa();        /* 注意函数名变了 */
    }

    /* TODO【A】：处理 OTA 下载事件 */
    if (SysEventFlag & OTA_EVENT)
    {
        SysEventFlag &= ~OTA_EVENT;
        if (CAT1_OTA(URL_ABuff, BemfaInfoCB.OTA_firelen) == 0)
        {
            BemfaInfoCB.OTA_flag = BOOT_STA_O;
            EEPROM_SaveInfo();
            NVIC_SystemReset();
        }
    }
}
```

## 第八章：常见问题

### Q1：烧录成功但串口没输出

**90% 是 IROM1 问题。** 见第二章坑 1。

**排查顺序：**

1. 串口助手波特率是 9600 吗？
2. Keil 的 IROM1 是 `0x08000000` 吗？
3. `VECT_TAB_OFFSET` 是 `0x0` 吗？
4. P8 跳线帽插了吗？
5. Keil 输出窗口有 `Programming Done` 吗？

### Q2：VS Code 满屏红波浪线

```powershell
Ctrl + Shift + P
→ C/C++: Reset IntelliSense Database
→ 回车
→ 等 30 秒
```

**还不行就检查：**

- 是不是装了 `C/C++ Runner` 插件？卸载它
- 右下角状态栏显示的配置名对不对？（STM32-APP / STM32-BootLoader）

### Q3：编译报 `undefined symbol`

**通常是 Keil 工程里少加了文件。**

```
Keil → 左侧 Project 树 → 右键某个 Group → Add Existing Files
```

**检查 `api` 组应该有 7 个 `.c` 文件：**

```
cat1.c  delay.c  eeprom.c  i2c.c  mqtt.c  spi.c  usart.c
```

### Q4：4G 模块没反应

**排查顺序：**

1. 模块 VIN 接 5V 了吗？（不是 3.3V）
2. GND 和 STM32 共地了吗？
3. TX/RX 交叉接了吗？（模块 TX → PB11，模块 RX → PB10）
4. **P5 跳线帽拔了吗？**
5. **K1 拨到 TXD 侧了吗？**
6. 模块上电后等 10~15 秒了吗？

### Q5：`AT+CPIN?` 报 `+CME ERROR: 10`

**SIM 卡没识别。**

```
断电 → 插卡 → 上电 → 等 15 秒
```

**模块只在开机时读卡。**

### Q6：巴法云连不上

**先确认参数。** 见 4.2 节。

**用 MQTTX 软件先测试：**

1. 下载 MQTTX（桌面软件）
2. 服务器填 `bemfa.com:9501`
3. Username / Password 都填 UID
4. 点连接

**MQTTX 能连上，说明参数对；连不上，说明参数错。**
