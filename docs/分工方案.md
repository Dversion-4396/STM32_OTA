# 二、发现的两个隐患（必须先修）

## 隐患 1：USART3 接收缓冲只有 256 字节 ⚠️

```c
#define USART3_BUFFER_SIZE (256)
```

**问题**：HTTP 下载时，一次 `AT+HTTPREAD=0,256` 会返回：
```
+HTTPREAD: 256\r\n          ← 16 字节
<256 字节二进制数据>         ← 256 字节
\r\n                        ← 2 字节
```
**总共约 274 字节，超过 256 的缓冲！** 会截断，导致数据错位。

**解决**：改成 **512 字节**（建议 1024 更保险）。

```c
#define USART3_BUFFER_SIZE (1024)
```

> 这个改动看起来小，但不改的话 HTTP 下载必然失败，而且很难查
> （现象是"下载的数据和原始 bin 对不上，但看不出哪里错"）。

## 隐患 2：USART3 中断里有业务逻辑 ⚠️

你的 `USART3_IRQHandler` 里现在直接处理了 PWM、蜂鸣器、LED：

```c
if (strstr(usart3_value.data + 3, "\"PWM\":0")) TIM3_CH4_PB1_PWM_Set_CCR4(1500);
if (strstr(usart3_value.data + 3, "\"Beep\":true")) Beep_On;
```

**问题**：这是给 WiFi 模块用的。4G 模块接上来后，AT 指令会误触发这些逻辑
（比如收到含 `"PWM"` 字样的数据就改 PWM）。

**解决**：中断里**只负责收数据**，业务逻辑移到主循环。

```c
void USART3_IRQHandler(void)
{
    /* RXNE：收一个字节 */
    if (USART3->SR & (0x01 << 5)){
        if(usart3_value.count < USART3_BUFFER_SIZE){
            usart3_value.data[usart3_value.count++] = USART3->DR;
        }else{
            USART3->DR;   /* 缓冲满，丢弃 */
        }
    }
    /* IDLE：一帧收完 */
    if(USART3->SR & (0x01 << 4)){
        USART3->DR;
        usart3_value.flag = 1;    /* 只置标志，不处理业务 */
    }
}
```

主循环里判断 `flag` 再处理。

> **这两个隐患我建议第一天就修**，否则后面调试会非常痛苦。

## 4.3 关键代码：基于你的串口框架

你的串口框架是 `usart3_value.flag` 标志位模式，AT 收发要这样写：

```c
/**
 * 发送 AT 指令并等待期望回复
 * 基于你的 usart3_value 结构
 */
u8 CAT1_SendAT(char *cmd, char *expect, u16 timeout_ms)
{
    u16 i;

    /* 1. 清标志 */
    usart3_value.flag = 0;
    usart3_value.count = 0;

    /* 2. 发送指令 */
    Usart3_SendString(cmd);
    Usart3_SendString("\r\n");

    /* 3. 等待回复 */
    for(i = 0; i < timeout_ms; i++){
        delay_ms(1);

        /* IDLE 中断置位，说明收到一帧 */
        if(usart3_value.flag){
            /* 检查是否含期望关键字 */
            if(strstr((char*)usart3_value.data, expect)){
                return 0;      /* 成功 */
            }
            /* 不是期望的，继续等下一帧 */
            usart3_value.flag = 0;
            usart3_value.count = 0;
        }
    }

    return 1;   /* 超时 */
}
```

> **注意**：你的 `usart3_value.data` 是 `u8` 数组，`strstr` 需要 `char*`，要强制转换。

## 4.4 HTTP 读取（关键：处理二进制数据）

```c
/**
 * 读取固件的一段
 * 注意：返回的是二进制数据，不能用 strstr 处理
 */
u8 CAT1_HttpRead(u32 offset, u16 len, u8 *outbuf)
{
    char cmd[64];
    char expect[32];
    u8 *ptr;
    u16 i;

    sprintf(cmd, "AT+HTTPREAD=%lu,%u", offset, len);
    sprintf(expect, "+HTTPREAD: %u", len);

    if(CAT1_SendAT(cmd, expect, 5000)) return 1;

    /* 定位数据起点 */
    ptr = (u8*)strstr((char*)usart3_value.data, expect);
    if(ptr == NULL) return 2;

    ptr += strlen(expect);
    /* 跳过 \r\n */
    while(*ptr == '\r' || *ptr == '\n') ptr++;

    /* 拷贝 len 字节（二进制，不能遇到 \0 停） */
    memcpy(outbuf, ptr, len);

    return 0;
}
```

> ⚠️ **这里有个坑**：`memcpy` 必须用 `len` 定长拷贝，
> **不能用 `strcpy`**（二进制数据里有 `0x00`，会被截断）。

## 5.3 关键：Flash 半字编程

**F103 是 2 字节半字编程**（G0 是 8 字节双字，不一样）：

```c
/**
 * 写 Flash —— F103 每次只能写 2 字节
 * @param addr  地址（必须 2 字节对齐）
 * @param buf   数据
 * @param len   字节数（必须偶数）
 */
u8 Flash_Write(u32 addr, u8 *buf, u32 len)
{
    u32 i;
    u16 halfword;

    if(addr % 2) return 1;
    if(len  % 2) return 2;

    FLASH_Unlock();
    FLASH_ClearFlag(FLASH_FLAG_EOP | FLASH_FLAG_PGERR | FLASH_FLAG_WRPRTERR);

    for(i = 0; i < len; i += 2){
        /* 小端拼装 */
        halfword = (u16)buf[i] | ((u16)buf[i+1] << 8);

        if(FLASH_ProgramHalfWord(addr + i, halfword) != FLASH_COMPLETE){
            FLASH_Lock();
            return 3;
        }
    }

    FLASH_Lock();
    return 0;
}
```

## 5.4 你的 EEPROM 可以复用

你的 `eeprom.c` 已经有 `EEPROM_WriteByte` / `EEPROM_ReadByte`，
只要在外面包一层结构体读写：

```c
u8 EEPROM_SaveInfo(void)
{
    u8 *p = (u8*)&AliInfoCB;
    u16 i;

    for(i = 0; i < sizeof(AliInfoCB); i++){
        if(EEPROM_WriteByte(EEPROM_AT24C02_ADDR, i, p[i]) != I2C_ACK)
```

## 7.3 SPI 驱动要点

**战神V1 的 W25Q128 接 SPI2**：

| 信号 | 引脚 |
|---|---|
| CS | **PB12** |
| SCK | PB13 |
| MISO | PB14 |
| MOSI | PB15 |

```c
void SPI2_Init(void)
{
    GPIO_InitTypeDef gpio;
    SPI_InitTypeDef  spi;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB1PeriphClockCmd(RCC_APB1Periph_SPI2, ENABLE);

    /* PB13/14/15 复用推挽 */
    gpio.GPIO_Pin   = GPIO_Pin_13 | GPIO_Pin_14 | GPIO_Pin_15;
    gpio.GPIO_Mode  = GPIO_Mode_AF_PP;
    gpio.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &gpio);

    /* PB12 = CS，推挽输出 */
    gpio.GPIO_Pin  = GPIO_Pin_12;
    gpio.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_Init(GPIOB, &gpio);
    GPIO_SetBits(GPIOB, GPIO_Pin_12);

    spi.SPI_Direction         = SPI_Direction_2Lines_FullDuplex;
    spi.SPI_Mode              = SPI_Mode_Master;
    spi.SPI_DataSize          = SPI_DataSize_8b;
    spi.SPI_CPOL              = SPI_CPOL_High;      /* W25Q128 用 Mode 3 */
    spi.SPI_CPHA              = SPI_CPHA_2Edge;
    spi.SPI_NSS               = SPI_NSS_Soft;
    spi.SPI_BaudRatePrescaler = SPI_BaudRatePrescaler_4;   /* 18MHz */
    spi.SPI_FirstBit          = SPI_FirstBit_MSB;
    spi.SPI_CRCPolynomial     = 7;
    SPI_Init(SPI2, &spi);

    SPI_Cmd(SPI2, ENABLE);
}
```

> ⚠️ **PB12 不能当普通 IO**：它接 W25Q128 片选，
> 悬空或误拉低会让 W25Q128 一直占线，SPI2 报废。

# 八、新的时间线

| 周 | A（你·4G） | B（BootLoader） | C（MQTT） | D（SPI+集成） |
|---|---|---|---|---|
| **W0** | 修隐患 + 量电压 + 买配件 | 裁剪工程 | 阿里云建产品/设备 | **写 SPI 驱动** |
| **W1** | USB-TTL 测通；**验证 SAPBR/HTTP** | Flash 擦写 | 移植加密库 | W25Q128 自测 |
| **W2** | 接线 + GPIO + AT 框架 | 串口菜单 + EEPROM | 移植 MQTT + 连接 | 修串口隐患 + 建 APP 工程 |
| **W3** | HTTP 下载 + 写 Flash | 搬移 + 跳转 | 版本上报 + OTA 解析 | **集成联调** |
| **W4** | 联调排错 | 固件校验 | 升级包 + 全链路 | 测试 + 文档 |

**关键节点**：
- **W0 末**：D 的 SPI 驱动必须出来（A 和 B 都要用）
- **W1 中**：A 验证 AT 指令（门禁 1）
- **W3 末**：完整走通一次 OTA
- **W4 末**：测试报告 + 答辩材料

# 九、接口约定（第一天锁死）

## 9.1 SPI/W25Q128 接口（D 实现，A 和 B 调用）

```c
void W25Q128_Init(void);
u16  W25Q128_ReadID(void);                                  /* 应为 0xEF17 */
void W25Q128_Erase_Sector(u16 sector);                      /* 4KB */
void W25Q128_Erase_Block(u8 block);                         /* 64KB */
void W25Q128_Write_Page(u8 *buf, u16 page);                 /* 256B */
void W25Q128_Read(u8 *buf, u32 addr, u32 len);
```

## 9.2 Flash 分区（BootLoader 和 APP 都要）

```c
#define FLASH_BASE_ADDR       0x08000000
#define FLASH_PAGE_SIZE       2048
#define FLASH_TOTAL_PAGES     256
#define FLASH_BOOT_PAGE_NUM   16
#define FLASH_BOOT_SIZE       (FLASH_BOOT_PAGE_NUM * FLASH_PAGE_SIZE)   /* 0x8000 */
#define FLASH_A_ADDR          (FLASH_BASE_ADDR + FLASH_BOOT_SIZE)       /* 0x08008000 */
#define FLASH_A_START_PAGE    16
#define FLASH_A_PAGE_NUM      240
#define FLASH_A_SIZE          (FLASH_A_PAGE_NUM * FLASH_PAGE_SIZE)      /* 480KB */
```

## 9.3 EEPROM 结构体（两边必须完全一致）

```c
typedef struct{
    u8  valid_cer;                             /* 0xDD = 有效 */
    u8  ProductKeyBuff[PRODUCTKEY_LEN+1];      /* 12 */
    u8  DeviceNameBuff[DEVICENAME_LEN+1];      /* 33 */
    u8  DeviceSecretBuff[DEVICESECRET_LEN+1];  /* 33 */
    u8  Version_ABuff[VERSION_LEN+1];          /* 24 */
    u32 OTA_firelen;
    u32 OTA_flag;                              /* 0x5AA5C33C = 需要OTA */
} AliyunInfo_CB;
```

## 9.4 串口接口（已有，直接用）

```c
void Usart1_Init(u32 brr);          /* 调试，PA9/PA10 */
void Usart3_Init(u32 brr);          /* 4G，PB10/PB11 */
void Usart1_SendString(const char *str);
void Usart3_SendString(const char *str);
extern USART_Data usart3_value;     /* 接收缓冲 + flag */
```

> ⚠️ **缓冲大小要从 256 改到 1024**（见第二节隐患 1）。
