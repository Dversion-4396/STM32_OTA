## 三、第一天必须锁死的 3 项接口

### 3.1 Flash 分区

```c
#define FLASH_BASE_ADDR       0x08000000
#define FLASH_PAGE_SIZE       2048
#define FLASH_TOTAL_PAGES     256
#define FLASH_BOOT_PAGE_NUM   16
#define FLASH_BOOT_SIZE       (FLASH_BOOT_PAGE_NUM * FLASH_PAGE_SIZE)   /* 0x8000 */
#define FLASH_A_ADDR          (FLASH_BASE_ADDR + FLASH_BOOT_SIZE)       /* 0x08008000 */
#define FLASH_A_START_PAGE    16
#define FLASH_A_PAGE_NUM      240
#define FLASH_A_SIZE          (FLASH_A_PAGE_NUM * FLASH_PAGE_SIZE)      /* 480KB */
```

| 工程 | IROM1 | VECT_TAB_OFFSET |
|---|---|---|
| BootLoader | `0x08000000` / `0x8000` | **`0x0`** |
| APP | `0x08008000` / `0x78000` | **`0x8000`** |

### 3.2 EEPROM 结构体（两边必须完全一致）

```c
typedef struct{
    u8  valid_cer;                             /* 0xDD = 有效 */
    u8  ProductKeyBuff[12];                    /* 11+1 */
    u8  DeviceNameBuff[33];                    /* 32+1 */
    u8  DeviceSecretBuff[33];                  /* 32+1 */
    u8  Version_ABuff[24];                     /* 23+1 */
    u32 OTA_firelen;
    u32 OTA_flag;                              /* 0x5AA5C33C = 需要OTA */
} AliyunInfo_CB;
```

> ⚠️ 存在 24C02 地址 0，两个工程靠它通信。
> **任何字段改动必须两边同步**，否则读出来是乱码，
> 表现为「OTA 标志读不到，永远不升级」——最难查的 bug。

### 3.3 W25Q128 接口（D 实现，A/B 调用）

```c
u32  W25Q128_ReadID(void);                        /* 应返回 0xEF4018 */
void W25Q128_EraseSector(u16 sector);             /* 4KB */
void W25Q128_EraseBlock(u8 block);                /* 64KB */
void W25Q128_WritePage(u16 page, u8 *buf);        /* 256B */
void W25Q128_Read(u32 addr, u8 *buf, u32 len);
```

## 四、两个必须先修的隐患

### 隐患 1：USART3 缓冲只有 256 字节 ⚠️

HTTP 下载一次返回约 **274 字节**（16 字节头 + 256 数据 + 2 字节尾），**会截断**。

→ **改成 1024**

### 隐患 2：USART3 中断里有业务逻辑 ⚠️

现在中断里处理 PWM、蜂鸣器、LED（给 WiFi 用的）。4G 接上来会误触发。

→ **中断只收数据置 flag，业务逻辑移到主循环**

**负责人**：A 和 D 各改一份（A 改 APP，D 改基础工程）

## 六、四个门禁

| 门禁 | 时间 | 内容 | 不通过的后果 |
|---|---|---|---|
| **门禁1** | W1 中 | `AT+SAPBR=1,1` 和 `AT+HTTPINIT` 返回 OK | HTTP 方案不可行，要改 MQTT 分片 |
| **门禁2** | W1 末 | D 的 SPI 驱动读 ID = `0xEF4018` | A 和 B 都无法存固件 |
| **门禁3** | W3 末 | 完整走通一次 OTA | 核心目标未达成 |
| **门禁4** | W4 中 | 4 类异常场景都不变砖 | 答辩演示可能翻车 |

> **门禁1 和门禁2 都在第一周**，是最关键的两道。
