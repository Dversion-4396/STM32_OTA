## 3. 存储资源（用户最常问）

| 器件 | 容量 | 接口 | 引脚 |
|---|---|---|---|
| **W25Q128**（U3）SPI NOR Flash | 16 MB（128 Mbit） | SPI2 | CS=**PB12**、SCK=PB13、MISO=PB14、MOSI=PB15 |
| **AT24C02**（U8）EEPROM | 2 Kbit（256 B） | I2C1 | SCL=**PB6**、SDA=**PB7**，4.7K 上拉 |
| **SD 卡**（SD1） | 按卡 | SDIO | D0=PC8、D1=PC9、D2=PC10、D3=PC11、SCK=PC12、CMD=PD2，47K 上拉 |
| MCU 片内 | 512 KB Flash / 64 KB SRAM | — | — |

### 总线冲突点（实战关键，v2 新增）

- **SPI2（PB13/14/15）被两个器件共用**：
  - W25Q128（U3），CS = **PB12**（F_CS）
  - WIRELESS / NRF24L01（P6 座），CS = **PG7**、CE = PG8、IRQ = PG6
  - → 同时使用时必须分别控制 CS，否则抢总线。
- **PB12 不可当普通 IO**：悬空或误拉低会让 W25Q128 一直占线，SPI2 报废。
- **I2C1（PB6/PB7）** 只挂 AT24C02，4.7K 上拉，无冲突。
- **SPI1（PA5/6/7）** 专供 VS1053 音频解码；xlsx 注明禁 VS1053 片选/保持复位后可当普通 IO。

## 5. RS485 引脚（v1 结论，已复核无误）

| MCU 引脚 | LQFP144 脚号 | 功能 | 去向 |
|---|---|---|---|
| **PA2** | 36 | USART2_TX / 485_RX | U2 第 4 脚 DI |
| **PA3** | 37 | USART2_RX / 485_TX | U2 第 1 脚 RO |
| **PD7** | 123 | RS485_RE | U2 第 2/3 脚（/RE 与 DE 并联），方向控制 |

- 命名陷阱：网络名按 **MCU 视角**命名。`RS485_RX` = MCU 收到的数据，走 RO → **PA3**；`RS485_TX` = MCU 发出的数据，走 DI → **PA2**。
- U2 的 A(6)/B(7) 差分侧有 120 Ω 端接。

## 7. 电源与时钟（v2 新增）

- 原理图的电源**不走 NL 网络标号**，用的是电源端口符号，所以按网络名搜不到 VCC/GND。
- 存在 `VREF_` 网络（ADC 基准）。
- `VOUT1` / `VOUT2` 是 LDO 输出位号；`BAT` 是备份电池座。
- MCU 主晶振 8 MHz（HSE），工程里 `HSE_VALUE` 需与之一致。
- RTC 晶振 32.768 K 在 PC14/PC15（Y2）。

## 10. 解析经验（重要，v2 修正）

原理图 PDF 已有同名 `.pdf.text.txt` 纯文本，**无需 OCR**。

### token 格式

| 前缀 | 含义 | 例子 |
|---|---|---|
| `PI` | 引脚 | `PIU60123` = U6 第 123 脚；`PIP1034` = P10 第 34 脚 |
| `NL` | 网络名 | `NLPA0` = PA0；`NLRS4850RE` = `RS485_RE` |
| `CO` | 元件位号 | `COU6` |

### ★ 三个必知的坑

1. **位号含数字**（U6 / U2 / P10 / JP1 / R18 / USB23）
   解析必须用 **CO 声明表做最长前缀匹配**。
   用 `[A-Z]+` 会把 `U6` 拆成 `U` + `60123`；用非贪婪 `[A-Z][A-Z0-9]*?` 会拆成 `U` + `60123`。两者都错。

2. **分组规则是 `[一串PI][一串NL]`**
   连续的引脚后紧跟连续的网络名，这些引脚**共享这些网络名**（互为别名/同一网络）。
   例：`PIP10040 PIU6034 NLPA0 NLWK0UP` → P10.40 与 U6.34 都接 PA0/WK_UP。
   第一组是元件引脚声明块（426 个引脚），需过滤（`len(pins) > 6`）。

3. **网络名里的字符 `0` 实为下划线**
   `NLRS4850RE` = `RS485_RE`，`NLUSART10TX` = `USART1_TX`，`NLF0CS` = `F_CS`。
   但 GPIO 名 `PA0` / `PB12` 末尾数字不受影响（转换时注意别把 `PA0` 变成 `PA_`）。
